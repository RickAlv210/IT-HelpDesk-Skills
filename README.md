# IT Helpdesk Skills

Hands-on practice repo documenting my helpdesk / IT support fundamentals — ticketing, Windows troubleshooting, remote support, and hardware diagnostics. Built to back up what I can actually do, not just list on a resume.

## ServiceNow — Incident Management

Set up a free ServiceNow Personal Developer Instance and worked full incident lifecycles: creation, categorization, prioritization, internal work notes vs. customer-facing communication, and resolution.

**Tickets created:**

| Ticket | Category | Priority | State |
|---|---|---|---|
| INC0010001 — User unable to log in after password expired | Inquiry / Help | 3 - Moderate | Resolved |
| INC0010002 — Software installation request (Adobe Acrobat Pro) | Software | 4 - Low | In Progress |
| INC0010003 — VPN connectivity issue from home | Network | 2 - High | Resolved |

For each ticket I practiced:
- Setting Impact/Urgency to drive Priority correctly
- Writing internal **Work notes** (technical detail, not customer-facing)
- Writing customer-facing **Comments** (plain language, reassuring tone)
- Moving tickets through state changes (New → In Progress/Resolved)
